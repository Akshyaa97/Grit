**Step-by-Step Guide:**

**Download the Extension:**
Click the green <> Code button at the top of this GitHub page and select Download ZIP (or grab the latest release from the Releases tab).

**Extract the Folder:**
Unzip the downloaded file (grit-main.zip) to a folder on your computer. (Make sure you remember where you saved it!)

**Open Chrome Extensions:**
Open Google Chrome and type chrome://extensions/ into your URL bar, then hit Enter.

**Enable Developer Mode:**
Look at the top right corner of the page and toggle Developer mode to ON.

**Import Grit:**
Click the Load unpacked button that appears in the top left corner.
Select the unzipped Grit folder you extracted in Step 2.

**Pin to Toolbar:**
Click the puzzle piece icon 🧩 in your Chrome browser menu, find Grit, and click the pin 📌 to keep it visible.


Boom. You're done. Click the Grit icon to open your dashboard and start reclaiming your focus.
